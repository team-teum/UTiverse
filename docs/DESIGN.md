# 유T버스 — MVP 시각 가이드

**방향: 그림은 개성을, UI는 일관성을.** 타이틀·튜토리얼의 손그림과 꾸미기의 픽셀 아트는 서로 다른 역할을 한다. 둘을 모든 화면에 섞지 않고, 공통 배경색·표면·정보 위계로 이어 준다.

| 영역 | 기준 | 적용 예 |
|---|---|---|
| 시작·온보딩 | 타이틀의 손그림과 티니가 주인공. 부드러운 빛과 따뜻한 별은 우주 분위기에만 가볍게 재사용한다. | 홈 성운과 비행 별빛은 트랜스젠더 프라이드 깃발의 하늘색·분홍색·흰색을 사용한다. 띠 대신 빛으로 표현하며 다른 화면이나 사용자 상태를 색으로 구분하지 않는다. |
| 캐릭터·우주선·소품 | 픽셀 아트는 사용자 공간과 꾸미기에 둔다. 픽셀 표현을 본문·폼·버튼에 흉내 내지 않는다. | 꾸미기 미리보기는 픽셀 아트, 조작 패널은 일반 글꼴과 선명한 테두리 |
| 탐색·공통 조작 | 짙은 배경 위에 읽기 쉬운 UI를 둔다. 기존 토큰 `--color-space`, `--color-panel`, `--color-stroke`, `--color-lavender-light`를 먼저 쓴다. | 홈 닉네임은 불투명한 보라색 표면과 옅은 보라 테두리. 조작 안내는 장면 아래에 배치. |
| 상태 표시 | 노랑은 포커스·선택에 남겨 두고, 색만으로 상태를 구분하지 않는다. 조작 요소의 글자와 영역은 작은 화면에서도 축소하지 않는다. | 홈의 앞쪽 별은 뾰족하고 이름이 붙는다. 뒤쪽 점은 작고 흐리며 선택되지 않는다. 링크는 44×44px 이상, 포커스에 윤곽선과 이름 밑줄. |

새 장면 에셋이 없으면 부드러운 배경색과 기존 토큰부터 쓴다. 새 그림이 오면 장식 레이어만 바꿀 수 있게 이름·고지·포커스는 HTML/CSS로 유지한다. 파일 교체·추가 규칙은 [에셋 가이드](./ASSETS.md)를 따른다.

**리뷰할 때:** 작은 모바일 폭에서 읽을 수 있는지, 키보드로 조작 위치가 보이는지, 장식이나 색이 빠져도 이름과 행동을 구분할 수 있는지 확인한다. 홈의 디자인 기준은 [Figma 50:6604](https://www.figma.com/design/aje3Gr9X9WnOsbhpabuHKB/?node-id=50-6604)의 어두운 공간·별 무리·이름표이며, 정적 이미지를 회전 구 대신 사용하지 않는다.
